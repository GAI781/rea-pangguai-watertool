安装与实机验证

本版本是入口验证工具（支持官方 SN / NQT / IMEI 入口格式和设备清单导入），尚未实现经过实测的无广告取水。保留官方认证与付款，工具自身不请求设备控制接口。

iPhone 使用

用 Safari 打开部署后的 HTTPS 地址，分享 → 添加到主屏幕。允许相机权限；拒绝权限也可选择二维码照片。首次使用扫描机身贴纸，核对屏幕显示的目标域名，命名后保存。每次打开入口都需重新确认来源。清理 Safari 数据会清空记录。

无需部署，先用系统快捷指令查明入口

  1. 打开 iPhone「快捷指令」，新建快捷指令，命名「校园取水入口诊断」。
  2. 添加「扫描二维码或条形码」（不同 iOS 版本可搜索“扫描”）。
  3. 添加「拷贝至剪贴板」，输入选上一步扫描结果。
  4. 添加「显示结果」，显示扫描结果。到这一步不会打开链接或提交订单。
  5. 复制原文或截下显示结果，反馈给开发者；不要提供手机号、验证码、token 或支付凭证。

可以拍下机身二维码直接交给开发者分析，不必自行提取原始内容。此诊断指令不是无广告取水成品。

无需部署的官方小程序快捷入口

取得开发者提供的冷水/热水专属链接清单。在快捷指令中添加「URL」，粘贴完整 alipays 链接，再添加「打开 URL」，命名后添加到主屏幕。每台设备各建一个。该链接格式已从官方网页核对，用户已在 iPhone 分别进入冷水、热水设备页，页面仍有商品推广。用户已确认正常出水与扣费；首次只观察设备/登录页面，不点开水或支付。也可在本工具识别 SN 码后展开「复制到 iPhone 快捷指令」。

一次实机验收

  1. 先拍机身二维码并遮住个人信息；扫码结果只在本机处理。
  2. 打开入口助手，选择照片或扫码。确认原文域名来自现场贴纸；无法识别时停止，不猜设备编号。
  3. 点「打开原始入口」，记录是否唤起官方 App、到达哪个页面、广告是否出现。若停留 Safari，尝试 Safari 内打开原码，记录差异。
  4. 核对官方页面设备位置、价格、账号，停在支付/开水确认前。无需为诊断付款。
  5. 只有你决定真实取水时，在官方页面单次确认；等待官方订单结果，状态不明时查看官方订单，不反复重试。

请反馈二维码照片、iOS/胖乖生活版本、跳转页面和广告情况。工具不会把浏览器跳转当作开水成功。

新设备的格式兼容报告

扫描或粘贴新设备码并检查后，可点击「导出格式兼容报告」。报告不包含二维码原文、设备标记值或查询值，不自动上传。它保留域名、格式及支持状态，帮助后续适配；域名可能标识学校，分享前可先检查。报告不代表设备已经验证或能正常出水。

不同型号的适配范围

普通官方 SN/NQT/IMEI 码可动态生成小程序入口；其中只有本次楼层 SN 路线已有用户正常取水反馈，其他型号还需核对。特殊公司分流参数保留原始入口；非 URL 中卡码、蓝牙型号及其他品牌尚不能保证适配。不猜设备号、不直接控制水阀。

收藏与备份

网页版的常用设备显示在首页前面，已适配的设备码可点「打开支付宝」并核对名称、尾号。导出设备备份会下载 JSON，可在换浏览器后重新导入；不要公开分享设备清单。

Windows 本地运行

npm ci
npm run dev
npm test
npm run build

安装 Node.js 24 LTS 后，在项目目录 PowerShell 运行。开发服务仅供电脑测试；iPhone 访问局域网 HTTP 通常无法调用相机。完整源码中的 README 提供免费 HTTPS 静态部署方式，无需长期服务器。
