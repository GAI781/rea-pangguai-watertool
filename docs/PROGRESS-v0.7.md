## Android 运行环境

已获得本次研究需要的会话网络权限，本机 ADB 调试套接字可用。此前「权限取消」是历史状态，本轮已实际执行测试。

- API 24 ARM64：ADB 连通，但 Android 系统在 libart.so 中出现 SIGSEGV，boot_completed 未成立。尚未安装 App，不能归因于胖乖生活。
- API 28/27 ARM64：当前软件后端尝试添加 PCI 音频设备，ranchu 板不提供该总线；关闭输入输出及选择 Virtio 音频仍未解决，不把该后端启动错误记成 App 失败。
- API 24 armeabi-v7a：匹配 APK 提供的 32 位库，系统返回 sys.boot_completed=1、启动动画停止，系统包管理可查询。
- 官方 APK 安装返回 Success，App 进程被观察到，截图显示官方启动图；Activity 的等待状态为 timeout。只证明 APK 已安装并开始启动，不代表登录、扫码、计费业务已就绪。

所有测试均在自建空白 AVD 中进行，没有用户账号、真实二维码提交、开水或支付操作。原始结果见 evidence/runtime-arm32-result.json。后续继续观察初始化和只读类元数据，若被软件环境或 App 保护拒绝，不虚构业务恢复结果。
