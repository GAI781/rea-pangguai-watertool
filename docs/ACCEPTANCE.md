# 最终交付与验收

用户已在自己的未越狱 iPhone 上运行快捷指令，并确认正常出水、正常扣费。冷、热水入口分别到达对应设备页已有截图；实际用水反馈未逐项指明两台交易，故不宣称每台设备均完成交易测试。

实际流程：主屏幕快捷指令 → 支付宝官方小程序设备页 → 用户在官方页面确认用水 → 出水、官方正常计费。

跳过的是胖乖生活 App 首页及其自动跳转广告。支付宝小程序设备页仍有商品推广，产品定位为减少广告和步骤的快捷入口，不是完全无广告客户端。不需要部署、Mac、越狱、账号代理或长期服务器。

| 原验收要求 | 证据与结论 |
|---|---|
| 普通 iPhone 可运行 | 用户 iPhone 截图与使用反馈 |
| 不必手动进入 App 广告首页 | 用户确认快捷指令直达支付宝官方服务 |
| 正确选择设备 | 冷、热水两条入口分别显示对应楼层设备页 |
| 正常身份与计费流程 | 官方小程序处理；用户确认正常扣费 |
| 不擅自发起支付或启动设备 | 项目代码只导航，官方用水操作由用户执行；未做自动订单或支付调用 |
| 不重复扣费或错误启动 | 当前用户未报告异常；不据单次成功保证所有未来交易和设备 |
| 减少广告和操作 | 用户确认跳过 App 首页自动跳转广告；小程序商品推广仍存在 |

可继续使用已配置的冷/热快捷指令，无需为更新文档重建指令。源码、静态网站和安装指南均随交付包保存，Windows 命令见 README。没有公网部署，也不需要它来使用现有快捷指令。

未来如官方路由改变，先保留机身二维码作为备用，用原码确认官方服务可用后再更新适配器；不要猜测设备 ID 或自动重试真实订单。适用范围是本次用户设备和使用反馈，不承诺所有学校、未来版本或长期可用性。
